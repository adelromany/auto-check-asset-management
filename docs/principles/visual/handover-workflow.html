Engineer does

System checks
Serial must match; CPU, positive RAM, and a disk must be present.
What blocks it

Missing software or unlicensed activation fails; the engineer can mark it not done with a reason.

4. Failure and recovery paths

Dashed red branches indicate a failure; the next action is stated beside it.

✕

device_status

Device status is not Ready to deploy

Next: Set the status in Snipe-IT, then record it again.

✕

agent_report

Agent report missing or serial/hardware invalid

Next: Run the agent again and resolve the reported mismatch.

✕

software_check

Required software missing or Windows not activated

Next: Install or activate, then re-evaluate; any override needs a reason.

✕

report_printed

Form did not print

Next: Check the selected printer and print the form again.

✕

recipient_check

Recipient not found in Snipe-IT

Next: Check the identity and ask an asset administrator to correct Snipe-IT.

✕

recipient_items

Recipient items could not be read

Next: Check the recipient in Snipe-IT and retry.

✕

checkout

Checkout verification does not match

Next: Refresh the asset state and resolve the current holder before retrying.

✕

document_scanned

Wrong file type or upload exceeds the limit

Next: Rescan to a supported file type and upload again.

✕

document_pushed

Push was not verified

Next: Check the asset exists and verify the attachment before retrying.

5. Case lifecycle

Lifecycle names are read from HandoverStatus. Derivation follows derive_status.

Statuses in code: draft, in_progress, ready, stalled, completed, closed_with_gaps, cancelled

  1. draft — Every stage is pending.
  2. in_progress — At least one operation has an outcome and the case is not closed.
  3. stalled — No activity for longer than STALL_HOURS (default 24; zero disables). A failure no longer stalls a case.
  4. completed — Every operation is passed; only passed counts as done.
  5. closed_with_gaps — The engineer closed the case while operations were not done; the gap list is stored.
  6. cancelled — Explicit cancellation; this status takes precedence.
